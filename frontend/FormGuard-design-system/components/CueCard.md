# CueCard

The coaching cue on screen, shown at the same moment the suit buzzes and the earbuds speak.

- **Consumer provides:** `joint` (the joint and fault, "Left knee caving"), `cue` (five words or fewer, exactly as spoken: "Knees out."), an optional `fix` (one sentence on how) and `meta` ("Rep 6 · Set 3").
- One CueCard at a time. If two faults happen at once, show the one that matters more for safety; the other waits for the set summary.
- The cue is set in the `heading` style so it can be read at arm's length; the fix is in `body`.
- **Don't** add encouragement or blame ("Oops!", "Great job"): name the joint, the cue and the fix.
