# Logos

The FormGuard logo is a heavy geometric **F** with a **Plate Red dot** in its counter. A halo cuts the dot free of the F, and the wordmark **FORMGUARD** is set in wide, heavy Archivo capitals (ExtraBold at 105% width). The dot is the joint being tracked; the halo is the space FormGuard watches around it. All files are outlined shapes, so no font is needed. The halo is a true cut-out, so the background shows through it on any surface.

## Which version on which background

- **Light background → positive. Dark background → reversed.** Use the file made for the background; never recolour one into the other by hand.
- **On Plate Red**, use the **white** one-colour logo (4.8:1). Never put the full-colour logo on red, because the dot disappears.
- **On photos**, pick by the area behind the logo: positive on light areas, reversed on dark ones. If the area is busy, place the logo on a solid Chalk or Iron Black panel instead.
- **One ink only?** Use black or white. The dot stays separate from the F because the halo is cut out. That's intended.

## Stacked or horizontal

- **Stacked:** the mark centred above FORMGUARD, the mark about three times the height of the capitals. Use it when the space is roughly square or taller.
- **Horizontal:** the mark stands in as the F of FORMGUARD, about 1.4 times the height of the capitals and sitting on the same baseline. Use it when the space is wide and short.
- Never rebuild either lockup by placing the mark next to a typed word: use the files.

## Clear space

Keep empty space around the logo equal to **twice the height of the mark's top bar** on every side. Nothing goes inside that space: no text, no edges, no other logos.

## Minimum sizes

| Version | Screen | Print |
| --- | --- | --- |
| Horizontal logo | 120px wide | 30mm wide |
| Stacked logo | 96px wide | 25mm wide |
| Mark alone | 24px tall | 6mm tall |
| App icon | 16px (favicon) | — |

Below these sizes the halo closes up and the dot merges into the F. At favicon size (16px) the dot is only about 2px across. It still shows, but use 32px or larger wherever the platform allows.

## Don't

- Stretch, skew, rotate or outline the logo.
- Change the colours, or swap Plate Red for any other red.
- Fill in the halo, move the dot, or change its size.
- Rebuild the wordmark in live type: the letterforms and spacing are drawn, not typed.
- Add effects: shadows, glows, gradients or bevels.
- Put the logo on a background that fails 3:1 contrast with the F.
